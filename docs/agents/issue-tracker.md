# Issue tracker: GitHub

Issues and planning artifacts for this repository live in GitHub Issues at
`rheajt/rheajt.github.io`. Use the `gh` CLI for issue operations.

## Wayfinding operations

- The map is a single issue labelled `wayfinder:map`.
- Child tickets use `wayfinder:research`, `wayfinder:prototype`,
  `wayfinder:grilling`, or `wayfinder:task`.
- Use GitHub sub-issues and native issue dependencies when available.
- Claim tickets by assigning them to the driving developer before work.

## Pull requests as a triage surface

PRs are not treated as feature requests by default.
